# 青山学院大学 米山研究室 UAVグループ ウェブサイト

青山学院大学理工学部電気電子工学科・米山研究室UAVグループのウェブサイトです。
固定翼UAVとPPGを対象とした飛行制御、システム実装、実機飛行試験を紹介します。

## 主なページ

- `index.html`：トップページ
- `about.html`：UAVグループ紹介
- `research/uav.html`：UAV研究概要
- `research/fixed-wing.html`：固定翼UAV研究
- `research/ppg.html`：PPG研究

## ローカルプレビュー

VS Codeでこのフォルダーを開き、`index.html`を選択して右下の **Go Live** をクリックします。

## 公開

GitHub Pagesを使用して公開します。公開対象はWeb表示用ファイルのみで、`assets/originals/`および`.hermes/`の元画像・添付ファイルは含みません。
